# Bravelyn Digital Academy – Launch Checklist

Use this before launching the site to the public.

## Branding and copy

- [ ] Brand name is consistent everywhere: “Bravelyn Digital Academy”
- [ ] No placeholder, mock, demo, or sample wording remains
- [ ] Page titles, headings, and meta content reflect the correct page purpose
- [ ] Navigation links match the actual pages
- [ ] CTA text is polished and conversion-focused
- [ ] Contact details are accurate and ready for production

## Firebase setup

- [ ] Firebase project exists and is activated
- [ ] Authentication is enabled
- [ ] Email/Password is enabled
- [ ] Google sign-in is enabled if required
- [ ] Authorized domains are configured
- [ ] Live Firebase configuration is in use
- [ ] Auth flows are tested in production mode

## Product readiness

- [ ] Landing page is polished and consistent visually
- [ ] Programmes, About, Learning, FAQ, and Contact pages are correct and complete
- [ ] Dashboard and auth flows work as intended
- [ ] All forms work correctly
- [ ] No broken links or missing pages remain
- [ ] Mobile responsiveness is tested
- [ ] Security and auth guard conditions are working

## Launch sign-off

- [ ] Site is deployed over HTTPS
- [ ] Real Firebase credentials are active
- [ ] No mock or placeholder auth remains
- [ ] Final QA is complete
- [ ] Site is ready for public launch
